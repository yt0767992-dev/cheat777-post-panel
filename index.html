# — এই চ্যানেলে পোস্ট যাবে

এমবেড (সুন্দর কালার বক্স)

কোথায় পাঠাবে

Enter = পোস্ট • Shift+Enter = নতুন লাইন • ফাইল টেনে এনেও দিতে পারো • সর্বোচ্চ ১০টি ফাইল, প্রতিটি 25 MB

চ্যানেল সেটিংস

Discord সার্ভারে Settings → Integrations → Webhooks → New Webhook গিয়ে URL কপি করে এখানে বসাও। প্রতিটি চ্যানেলের জন্য আলাদা webhook বানালে সবগুলো বাঁ পাশে দেখাবে।

দেখানো নাম/এভাটার খালি রাখলে ওয়েবহুকের নিজের নাম ব্যবহার হবে (যেমন CHEAT 777)।
