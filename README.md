# CHEAT 777 — Post Panel

একটা ছোট Discord-style ওয়েবসাইট যেখানে টেক্সট লিখে বা ফাইল আট্যাচ করে সরাসরি
Discord চ্যানেলে পোস্ট করা যায়।

কোনো সার্ভার লাগে না — পুরোটা ব্রাউজারেই চলে, Discord-এর ফ্রি **Webhook**
ব্যবহার করে।

## ব্যবহার

1. ওপেন করো: **https://yt0767992-dev.github.io/cheat777-post-panel/**
2. প্রথমবার একটা সেটিংস বক্স খুলবে — সেখানে তোমার **Webhook URL** বসাও
   (Discord সার্ভারে: **Settings → Integrations → Webhooks → New Webhook**
   → চ্যানেল সিলেক্ট → **Copy Webhook URL**)
3. টেক্সট লেখো বা ➕ চেপে ফাইল আট্যাচ করো
4. **Enter** চাপলেই পোস্ট হয়ে যাবে

আরও অনেক চ্যানেল যোগ করতে পারো — সবগুলো বাঁ পাশের লিস্টে দেখাবে।

## সীমা (Discord-এর নিয়ম)

- একসাথে সর্বোচ্চ **১০টি** ফাইল
- প্রতিটি ফাইল সর্বোচ্চ **25 MB**
- ছবি, ভিডিও, APK, ZIP — যেকোনো ফাইল যায়

## নিরাপত্তা

এই সাইটে কোনো ওয়েবহুক URL বসানো নেই। তোমার URL শুধু তোমার ব্রাউজারে
(localStorage-এ) থাকে, তাই কাউকে দিলেও ওটা চুরি হয় না।

## লোকালি চালাতে

`post-panel.html` ফাইলটা ডাবল-ক্লিক করলেই ব্রাউজারে খুলে যাবে — ইন্টারনেট
ছাড়াও ওটা দেখা যাবে (পোস্ট করতে ইন্টারনেট লাগবে)।
